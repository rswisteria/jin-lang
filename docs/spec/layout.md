## 2. 配置規則

- 紋は 12 時位置から**時計回り**、配列順、等角配置。n 個の紋の i 番目（0 始まり）の角度は
  `theta_i = -90° + 360° * i / n`（SVG の x 軸正方向を 0°、時計回りを正とする）
- 核 → tools の各紋へ放射線を引く
- `summon` は紋を入れ子の小陣として描く。**展開は深さ 1 まで**で、それ以下は点にする
- `delegate` は境界環の内側に小円を並べ、核と破線で結ぶ
- `sequence` = 開いた弦列（矢印）、`parallel` = 弦なし対称配置、`loop` = 閉じた多角形
- `await` の紋の角度に、境界環の欠けを作る
- rune は instruction 環に沿った `<textPath>`。v1 は可読フォント、グリフフォントは v2
- 白黒 2 値 + 強調 1 色（トレース時のみ）。`<style>` は使わず属性で完結させる

### 2.1 loop の星形多角形 {n/k}

`n >= 5` の loop は星形多角形 {n/k} で描く。**k の決め方を一意に定める**（要件書 §2.5 は
「n/2 未満の最大の互いに素な整数」とだけ書いており、実装で一意になるよう本文書で確定させる）:

```
k = max{ j : 1 <= j < n/2 かつ gcd(n, j) == 1 }
```

- `j` の探索は整数演算のみで行う（浮動小数点比較を使わない。`2*j < n` で判定する）
- 上式の集合は `j = 1` を必ず含むため空にならない（`gcd(n,1) == 1` かつ `n >= 5` なら `2*1 < n`）
- 候補が複数あるときは**最大の j** を採る。この規則により k は一意に決まる
- `n < 5` の loop は星形にせず単純な閉多角形（k = 1）で描く
- 辺の順は訪問順（`flow.steps` の配列順）に一致させる

例: n=5 → k=2（{5/2}）、n=6 → k=1、n=7 → k=3、n=8 → k=3、n=9 → k=4。

n=6 の内訳: `2*j < 6` を満たす候補は `j = 1, 2` だけである（`j = 3` は `2*3 < 6` が偽なので
**探索範囲に入らない**）。`gcd(6, 2) == 2` なので `j = 2` は落ち、残る最大値は `j = 1`。

### 2.2 装飾（識別紋章）

装飾（小点・飾り）は `instruction.rune` の **SHA-256** から決定的に生成する。
乱数・時刻・辞書順序に依存させない。`rune` を持たない circle には装飾を描かない。

## 3. data-jin 属性の契約（エディタとの接点）

描画された**すべての**要素は次の 2 属性を持つ。

- `data-jin="<JSON Pointer>"` — 例 `/circles/0/tools/2`
- `data-jin-kind="<種別>"`

<!-- machine-readable: data-jin-kinds -->

| `data-jin-kind` の値 | 対象 |
|---|---|
| `circle` | 陣（同心円のまとまり） |
| `core` | 核 |
| `rune` | 指示環の文字列 |
| `tool` | 道具環の紋 |
| `state` | 記憶環の四角 |
| `flow-edge` | flow の弦・矢印 |
| `guard` | 境界環の刻印 |
| `await` | 境界環の欠け |
| `delegate` | 境界環内側の小円と破線 |

<!-- /machine-readable -->

ポインタはファイル内の位置とレンダリングを結ぶ**唯一の鍵**であり、
`jin/model` が返す pointer→range 対応表と一致すること（`docs/spec/model.md` §6）。

  素の float 文字列化を混在させない

  Phase 3 の実装者はここに桁数と根拠を追記すること
