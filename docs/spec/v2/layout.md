# Jin v2 決定的レイアウトと data-jin 属性(layout.md)

> 正典。設計書 §7 の実装仕様。実装は Phase 3 の `jin_render.v2`。
> v1 `docs/spec/layout.md` の規律(正方形キャンバス、R=1、12 時から時計回り、`fmt_coord` 1 本、
> 3 桁固定小数、`-0.0` の正規化、楕円弧 `A` 不使用、2 色 + 強調 1 色、`<style>` 不使用、`xml_chars`)を
> **すべて継承**する。ここには v2 で決めることだけを書く。
> 実装は `packages/jin-render/src/jin_render/v2/`（Phase 3・実装済み）。§3 の弧の割り当てと §8 は
> Phase 3 の実装で確定させた。

## 1. 舞台と陣の配置

- 出力は 1 枚の SVG。最外に**額縁**(`stage`)を描く: 正方形の枠(半辺 1.18・§8)と、上辺の外側に `width×height @fps` の文字列。額縁と印章は**手順の図でも**描く
- 型紙(`forms`)は額縁の**左上の隅**に印章として並べる(小さな正方形に頭文字。配列順に右へ)。組み込みの `Pointer` は描かない(`forms` に無い)
- 陣は v1 と同じ入れ子規則で配置する: `root` を中央に、核なし陣(`flow`)は子を弦 / 多角形で結び、核あり陣は同心円。**展開は深さ 1 まで**、以下は点(v1 §2)
- `--focus <陣名>` でその陣を中央に。`--focus <陣名>/<手順名>` で §3 の手順の図

## 2. 核あり陣の環

<!-- machine-readable: ring-radii -->

| 環 | 半径 | 中身 |
|---|---|---|
| rites | 0.35 | 手順環。手順ごとに小陣(半径 0.07)。`core` の手順へ核から実線 |
| sigils | 0.55 | 道具環。`host` は名前空間の紋(円に頭文字)、`summon` は入れ子の小陣(深さ 1) |
| state | 0.75 | 記憶環。四角。`out: true` は二重線 |
| boundary | 0.95 | 境界環。`on` は刻印(◇ + イベント名の頭文字)、`guards` は刻印(△)。`delegate` は内側に小円と核への破線 |

<!-- /machine-readable -->

半径の値は v1 と同じ 4 本(`instruction` の 0.35 を `rites` が引き継ぐ)。存在しない環は描かず、半径も詰めない。環を描く条件: rites は `rites` が空でないとき、sigils は `sigils` が空でないとき、state は `state` が空でないとき、boundary は `boundary` があるか `delegate` が空でないとき。核なし陣は環を 1 本も描かない。

紋の角度は v1 と同じ `theta_i = -90° + 360° * i / n`(配列順)。境界環の刻印は `on` を先に、`guards` を後に、1 つの列として等角配置する。

核から道具環の各紋へ放射線(v1 と同じ)。核の中には `core` の手順名を書く(v1 の核はモデル名。8 文字を超えたら 7 文字 + `…`)。`core` が `rites` に無ければ(JIN011)核を破線にし、核から手順環への実線と装飾(§5)は描かない。手順環の小陣・`host` の紋・`on` の刻印には**頭文字**(大文字 1 字)を書く。核なし陣は環を描かず、`flow.steps` の節を道具環と同じ 0.55 に置く(弦・星形・`exit` の印・節の縮小はすべて v1 §2.1 / §6 と同じ規則)。

## 3. 手順の図(`--focus 陣名/手順名`)

手順を 1 つの陣として描く。中心の核には手順名(`data-jin` は `…/rites/j/name`)。ステップは**深さ 0** を半径 0.95 の環に、深さ 1 を 0.75、深さ 2 を 0.55、深さ 3 を 0.35 に置く(外から内へ。深さ 4 以上は JIN211 のエラー状態で、描くときは最内環 0.35 に丸める)。環は**その深さにステップがあるときだけ**描く。

**弧の割り当て**(Phase 3 で確定・`jin_render.v2.rite.place_block`):

- 深さ 0 のステップ `k`(`n` 個)は角 `theta_k = -90° + 360° * k / n`(v1 と同じ)に置き、幅 `360° / n` の弧 `[theta_k - 180°/n, theta_k + 180°/n]` を持つ
- 入れ子のブロック(`if.then` / `if.else` / `loop.steps`)は**親の弧**に収める。`if` に `then` と `else` の両方があれば弧の**前半**(反時計回り側)を `then`、**後半**を `else` に割る。片方だけなら全幅。`loop.steps` は全幅
- ブロックの `m` 個の子は、その弧を `m` 等分した区画の**中央**に配列順で置き、子の弧幅は `弧幅 / m`。同じ規則を再帰する(深さ 3 まで)

「その環に置くステップの数で等角配置」ではなく**親の弧で割る**。前者だと `then` の中身が親から離れた角度に飛び、分岐の弦が環を横切って読めない(Phase 0 の記述の矛盾を Phase 3 で解消・設計書 §11 #29)。

<!-- machine-readable: step-glyphs -->

| ステップ | 図形 |
|---|---|
| `set` | 四角 |
| `let` | 小さな四角(辺は `set` の 0.6 倍) |
| `cast` | 円(紋)。target がホスト能力なら環の**外側**へ短い放射線、自陣の手順なら**内側**へ、summon なら破線 |
| `if` | 分岐の弦: 自分の紋から `then` の弧の両端へ実線、`else` の弧へ破線 |
| `loop` | 閉じた多角形(`count` / `while`)。`each` は星形(n ≥ 5 なら v1 §2.1 の {n/k}) |
| `break` | 環の外へ抜ける短い線(先端に横棒) |
| `wait` | 環の欠け(v1 の `await` と同じ記号) |
| `emit` | 環の外へ向かう破線(先端に小円) |
| `return` | 環の外へ抜ける短い線 |
| `finish` | 環の外へ抜ける短い線(先端に二重横棒) |
| `transfer` | 環の外へ向かう破線(先端に小さな陣) |

<!-- /machine-readable -->

`cast` の分類は**名前表だけ**で決める(意味検査を呼ばない): `target` が `summon` の sigil 名 → summon、自陣の手順名 → 手順、`名前空間.member` の名前空間が `host` の sigil 名 → ホスト能力、どれでもなければ**破線の円**(未解決)。`loop` の多角形の頂点数は `max(3, len(steps))`(`each` で 5 以上なら星形 {n/k})。`transfer` の先端の小さな陣は委譲先へ `data-jin-ref` を持ち、解決できなければ破線。

ステップ間は配列順に**弦**で結ぶ(矢じり付き。実行順。`data-jin-kind` は `step-edge`、pointer は始点側)。`if` / `loop` の紋からは各ブロックの**先頭と末尾**へ線を引き(`else` は破線。これは紋の一部で `kind` は `step`)、ブロックの中は同様に弦で結び、ブロックの末尾から**親の次のステップ**へ矢じり付きで戻る。`loop` は末尾から**紋へ**戻る(繰り返し)。

## 4. data-jin 属性

描かれた**すべての**要素は `data-jin`(JSON Pointer)と `data-jin-kind` を持つ(v1 §3)。

<!-- machine-readable: data-jin-kinds -->

| `data-jin-kind` | 対象 | pointer |
|---|---|---|
| `stage` | 額縁 | `/stage` |
| `form` | 型紙の印章 | `/forms/i` |
| `circle` | 陣(同心円のまとまり)、手順の図の外枠 | `/circles/i`、`/circles/i/rites/j` |
| `core` | 核 | `/circles/i/core`、手順の図では `/circles/i/rites/j/name` |
| `rite` | 手順環の小陣 | `/circles/i/rites/j` |
| `sigil` | 道具環の紋 / 入れ子の小陣 | `/circles/i/sigils/j` |
| `state` | 記憶環の四角 | `/circles/i/state/j` |
| `on` | 境界環の刻印(イベント) | `/circles/i/boundary/on/j` |
| `guard` | 境界環の刻印(不変条件) | `/circles/i/boundary/guards/j` |
| `delegate` | 委譲の小円と破線 | `/circles/i/delegate/j` |
| `flow-edge` | flow の弦 / 多角形の辺 | `/circles/i/flow/steps/j`(辺の始点側) |
| `step` | 手順の図のステップの図形 | ステップの pointer(`/circles/i/rites/j/steps/k`、入れ子は `…/then/m` / `…/else/m` / `…/steps/m`) |
| `step-edge` | ステップ間の弦 | 始点側ステップの pointer |

<!-- /machine-readable -->

**13 種**。v1 の 9 種とは別集合で、`jin_render.DATA_JIN_KINDS_V2` と `tests/contract/test_render_contract_v2.py` が等号で固定する。v1 §3.1 の約束(`<svg>` と `<defs>` は対象外 / 同じ pointer の要素が複数あってよい / `data-jin-ref` `data-jin-fired` `data-jin-seq` `data-jin-root` を足す)はそのまま。`data-jin-ref` を持つのは参照を表す要素(`summon` の紋・`flow.steps` の節・`delegate` の小円・`transfer` の先端)で、値は参照先の `/circles/<k>`。

## 5. 装飾(識別紋章)

v1 §2.2 の規則をそのまま使い、ハッシュの入力を `instruction.rune` から **`core` の手順の正準 JSON**(`rites[j]` のオブジェクトを正準形で直列化した UTF-8)に替える。`rites` が無い陣(核なし)には描かない。

## 6. トレースのオーバーレイ

v1 §7 と同じ規則(祖先一致 → referent 規則。`jin_render.layout.fired_indices` を共有)。`upto` までに発火した `pointer` の要素を強調色にし、境界環の外(環 1.10)に発火数の点を並べる(点の `kind` は `circle`、pointer は焦点の陣 / 手順)。手順の図では `step` / `step-edge` が対象。

- v2 のトレースの `seq` は `boot` から通しの **0 始まり**(runtime.md §5)。読み取りは `jin_render.overlay.read_trace(rows, min_seq=0)` で、v1 の既定(1 始まり)は変えない。`--upto 0` は `enter` 行 1 件を発火させる
- `frame` 行の pointer は `/stage` だが、額縁と型紙の印章は強調の対象に**入れない**(陣 / 手順の `<g>` の配下だけを走査する)。`frame` 行は点にだけ数える(画面はプレイヤー側で出す)
- 陣の図では、手順の中のステップの行(`/circles/i/rites/j/steps/…`)は祖先一致で**手順環の小陣**(`/circles/i/rites/j`)に落ちる。手順の図では焦点の手順の外の行(`enter` / 他の手順)はどの要素にも当たらず、点にだけ数える

## 7. エラー回復

v1 と同じ: schema を通るモデルなら意味エラーを含んでいても例外を投げない。未解決の参照は点線で、型紙の無い state は四角の中に `?` を描く。

| 状況 | 描き方 |
|---|---|
| `summon` / `flow.steps` / `delegate` / `transfer` の陣が無い(JIN011) | 破線の点。`data-jin` は参照側、`data-jin-ref` は付けない(v1 §5 と同じ) |
| `core` が `rites` に無い(JIN011) | 核を破線。核から手順環への実線と装飾は描かない |
| state の型が `num` / `bool` / `str` / 型紙名 / それらの `list<…>` に解決しない(JIN011) | 四角の中に `?` |
| `cast` の `target` が分類できない | 破線の円(§3) |
| `root` が未定義(JIN060) | `circles[0]` に落とし、陣全体を破線 + `data-jin-root="unresolved"`(v1 §5 と同じ) |
| 深さ 4 以上のステップ(JIN211) | 最内環 0.35 に丸めて描く(§3) |
| 手順にステップが無い / `boundary` に `on` も `guards` も無い | 環だけ(手順の図は核だけ)。等角配置の 0 除算をしない |

例外を投げるのは引数が壊れているときだけ: 未定義の `focus`(陣名 / 手順名。`/` が 2 つ以上)は `jin_render.RenderError`、トレース行の型違いは `ValueError`。**診断コードは増やさない**。

## 8. 実装で確定した値(Phase 3)

環の半径 4 本(§2)と v1 §6 から継承する値(キャンバス 1000 px / 正規化 400 px / 核 0.12 / 紋 0.06 / 四角の半辺 0.05 / 入れ子の縮尺 0.28 / 隙間 0.04 / 点 0.03 / 矢じり 0.05 / トレースの点 1.10・0.025 / 強調色 `#cc0000` / 3 桁固定小数)以外は、すべて **Phase 3 の実装で確定した値**で要件値ではない。実装は `jin_render.v2.geometry`。

| 項目 | 値 | 決め方 |
|---|---|---|
| 額縁の半辺 | 1.18 | トレースの点の環 1.10 + 半径 0.025 の外、キャンバス半幅 1.25 の内 |

| 核の手順名 | 高さ 0.045・8 文字まで(超えたら 7 文字 + `…`) | 核の直径 0.24 に `sans-serif` の 8 文字が収まる |
| 手順環の小陣 | 半径 0.07(§2 の表)・頭文字の高さ 0.06 | 環 0.35 上で 12 個(JIN020 の上限)並べても隣と重ならない(中心距離 0.181) |
