# 陣書き S2(完全陣レンダラ)Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `.jin`(v2)からプログラムの情報をすべて載せた 1 枚の SVG「完全陣」を決定的に描く(`jin render FILE --full`)。

**Architecture:** 既存の `jin_render.v2` の描画(陣の図・手順の図)を `<text>` 無しで再利用し、陣を第 1 軌道・手順陣を第 2 軌道に同じ升の大きさで並べ、
各陣・手順陣の外周に銘環(構造の印を頭にした銘帯の並び)を巡らせる。銘帯の中身(升の列)は `jin_render.v2.inscribe` が `.jin` から作り、
S3 の構文解析器が逆向きに使う。字形は線の紋(57 + 構造の印 21)とドットのラテン層(5×7 / k6x8)を Python のデータとして持つ。

**Tech Stack:** Python 3.12+ / 既存の `jin_render`(標準ライブラリ + `jin_core` だけ)/ pytest + syrupy

**Spec:** `docs/superpowers/specs/2026-10-03-jin-glyph-design.md`(§1.1 / §1.3 / §2 / §4.2 / §9 #24〜#27。以下 spec)、正典 `docs/spec/v2/glyph.md`

## Global Constraints

- `jin_render` は `jin_core` と標準ライブラリだけに依存し、ファイルを読まず、モジュールレベルの可変状態を持たない(純関数)
- 座標は `jin_render.svg.fmt_coord` 1 本(3 桁固定小数)。楕円弧 `A`・`<style>`・`style=`・`transform` を使わない。色は 2 色 + 強調 1 色
- **完全陣は `<text>` を 1 つも出さない**(spec §2.2)。銘文はすべてパス
- **既存の出力(`--full` 無し)は 1 バイトも変えない**(SVG スナップショット 9 本・`apps/stage/test/fixtures/play.svg`・チュートリアルの図が張り付いている)
- `data-jin-kind` は v2 の 13 種のまま(spec §9 #26)。銘環の升の pointer は「欄が正準形の JSON にあればその欄の pointer、無ければ持ち主の pointer」
- サブコマンドは 9 個のまま。`--full` は `jin render` のオプション。LSP の `jin/…` は 6 種のまま(`jin/renderSvg` に `full` を足さない)
- 生成物は手で編集しない(`docs/spec/v2/glyphs/*.svg` は S2 から `jin_render.v2.glyph_paths` の生成物、`font_data.py` は `scripts/generate_glyphs.py` の生成物)
- 升 1 つ = レイアウトの 1 単位。図の大きさは升で数えた固定値(下の Task 5 の表)
- コミットメッセージは日本語、末尾に `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`

## Review Focus

1. **銘環の 1 周目に入りきらない長い銘帯(tetris の 449 トークンの表)** → 周を増やし、各周の最後の升が `cont`(Task 5 のテスト)
2. **空の手順(steps が 0)・state も sigil も無い陣・陣 1 つだけのプログラム(fib)** → 例外を投げず、銘環は核の銘帯だけ(Task 5 / 6)
3. **意味エラーを含む schema 適合のモデル(未定義の手順を cast・未定義の陣を summon)** → 例外を投げず描く(既存のエラー回復と同じ・Task 6)
4. **非 ASCII の文字列(日本語)と k6x8 に無い文字** → k6x8 にあればその字形、無ければ □(プレイヤーと同じ・Task 3)
5. **`--full` と `--focus` / `--trace` / `--upto` の併用** → exit 2 と理由(Task 7)
